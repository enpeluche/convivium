# convivium

Outils interactifs qui accompagnent ma thèse sur le partage équitable. La page d'accueil (`index.html`) est publiée par GitHub Pages et renvoie vers :

- [`simulateur/`](simulateur/) : le simulateur de frustration ;
- [`carte-equite/`](carte-equite/) : la carte de l'équité.

Chaque outil marche seul, hors ligne, en français et en anglais (`?lang=fr` ou `?lang=en`). Les anciennes versions sont dans `archive/`.
